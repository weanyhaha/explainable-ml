# Интерпретация моделей машинного обучения

Учебное исследование глобальных и локальных методов объяснения предсказаний на данных World Happiness Report 2021. В ноутбуке сравниваются линейная регрессия, Lasso и градиентный бустинг, исследуется влияние масштабирования признаков и реализуются собственные варианты occlusion importance и LIME.

## Реализовано

| Раздел | Содержание |
|---|---|
| Подготовка данных | Предсказание `Ladder score`, разделение train/test, MinMaxScaler и StandardScaler |
| Интерпретация моделей | Коэффициенты линейной регрессии и Lasso, важности признаков бустинга, пересчёт коэффициентов между масштабами |
| Графики эффектов | ICE, PDP и ALE для линейной регрессии и бустинга |
| Важность признаков | Permutation importance и собственная функция `occlusion_importance` со сдвигом признака к медиане |
| SHAP | Глобальные и локальные объяснения: force, beeswarm и waterfall plots |
| LIME | Объяснения через `LimeTabularExplainer` и собственная локальная взвешенная линейная модель |

## Эксперименты и проверки

Результаты, сохранённые в ноутбуке:

- Lasso с `alpha=0.1`: test MSE **0,4888** с MinMaxScaler и **0,0298** со StandardScaler;
- градиентный бустинг с `max_depth=2`: test MSE около **0,0437** при обоих способах масштабирования;
- пересчёт коэффициентов линейной регрессии между MinMaxScaler и StandardScaler проверен через `assert`;
- ICE показывает линейную экстраполяцию регрессии и постоянные предсказания бустинга за пределами обучающего диапазона;
- исследована устойчивость permutation importance к числу перестановок и собственной реализации LIME к числу сэмплов и ширине ядра.

Метрики относятся к подготовленной версии данных из задания и выбранному набору признаков. В ноутбуке отдельно обсуждается столбец `Dystopia + residual`; состав признаков следует учитывать при интерпретации качества.

## Стек

Python, NumPy, pandas, scikit-learn, Matplotlib, PyALE, SHAP, LIME, JupyterLab.

## Запуск

Из каталога `explainable-ml`:

```bash
python -m pip install numpy pandas scikit-learn matplotlib pyale shap lime jupyterlab
jupyter lab homework-practice-bonus-XAI.ipynb
```

Перед выполнением ячейки `pd.read_csv` скачайте подготовленный CSV по ссылке из ноутбука и сохраните его рядом с ноутбуком как `world-happiness-report-2021-prep.csv`. Датасет в каталог не включён.

Ячейка загрузки использует внешнюю утилиту `wget`. Если она недоступна, скачайте файл вручную и пропустите эту ячейку. В ноутбуке также есть установка `fat-forensics[all]`, но выполненный код методов интерпретации этот пакет не использует.

Выполняйте ячейки последовательно: объяснения используют модели и преобразования, обученные в подготовительной части.
